# quick_sort
этот код сортирует произведение Пушкина "Евгений Онегин", но может и другие файлы 

использование:
```
./a.out [-f input.txt] [-o output.txt]
```
по умолчанию: onegin_eng.txt, answer.txt

в файле main.c находится весь необходимый код, остальные файлы не участвуют, и сохранены как старые версии для быстрого просмотра
старых реализаций

в файле main_alltypes_index.c находится реализация qsort на индексах
в файле main.c - "стандартная" реализация

изменяя функцию main, можно проверить обе программы для сдачи - Онегин по умолчанию и переключиться на сортировку цифр при желании

в начале есть
```
#define DEBUG_XXX if (0)
```
измените на 1 если необходима конкретная отладочная информация

сравнение во время сортировки выполняется только по буквам, игнорируя другие символы
